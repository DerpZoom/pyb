# PyB — Python Gap-Fill (30 days)

Fast-paced audit series: fill gaps, modernise idioms, lock in the uv + git + Obsidian + Claude Code workflow.

Part of the 210-day Python Mastery arc (PyB 30 → PyI 90 → PyA 90).
Daily lessons are generated from `python_exercise_config.md` by a
Claude Code scheduled task and delivered to `/Users/derpzoom/Projects/python-mastery/Daily Lessons/`.

## Daily workflow
1. `git checkout -b day-NN`
2. Work through the lesson docx
3. `uv run pytest` / `uv run ruff check .` as required
4. Merge to `main`, delete the branch — this marks the day complete
